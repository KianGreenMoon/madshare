Madnetwork

Friend other madshare nodes to build the madnetwork: exchange node cards out-of-band (chat, mail — any channel you trust) and import each other’s card here. A node becomes a friend only after both admins have acted.

Federation is turned off. Set [federation].enabled = true in madshare.toml and restart (requires a build without -tags nofederation) to join the madnetwork.
