Overview

Library Browse, edit metadata, set access, and remove library files. Review Review staged uploads: approve, return, or discard. Upload Add new audio files to the library. Users Create accounts; manage roles and passwords. Verify & Prune in progress Scan for dangling records and prune them. Duplicates Review same-audio recordings with more than one rendition. Recordings Curate recordings: renditions and appearances, merge, move, delete. Data sources scanning Import external folders in place via symlinks; no copying. Network Friend other madshare nodes: exchange node cards, manage peers. Upgrades Better renditions of what you already have, found on the madnetwork. Cache What the swarm fetched from other nodes — review it, free the disk. Trash Restore or permanently delete trashed files. Settings License-based auto-publish policy.
